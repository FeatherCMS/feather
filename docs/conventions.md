# Naming Conventions

Use names that match the responsibility and vocabulary of each layer.

## Domain

- `Model`
    - new

- `Repository`
     - insert
     - update
     - delete
     - get
     - getAll

## Application Use Cases

- `Add`
- `Edit`
- `Search`
- `Detail`
- `List`
- `Remove`

- Query: 
    - find
    - findAll 

DTO: 
    - input
    - output

## API Operations

- `Post`
- `Get`
- `Delete`
- `Put`
- `Patch`
- `Query`
- `List`

## Database Operations

- `Insert`
- `Update`
- `Delete`
- `Select`


- Row:
    - Insert
    - Update
    - Detail
    - List
